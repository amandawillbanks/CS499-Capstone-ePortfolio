# Journal Entry

An ePortfolio can be an effective tool for self-promotion because it allows employers to see practical examples of technical skills, problem-solving ability, and professional growth rather than only reading about them on a resume. Through projects, code reviews, enhancement narratives, and GitHub links, an ePortfolio demonstrates both technical knowledge and communication skills. In my portfolio, I used the Grazioso Salvare Dashboard project to showcase my ability to evaluate software, improve code structure, strengthen database design, and develop algorithmic enhancements. With all three enhancement categories now complete, the ePortfolio presents a full picture of growth across software design and engineering, algorithms and data structures, and databases, and demonstrates coverage of all five course outcomes.

While ePortfolios are valuable marketing tools, there are also risks associated with publishing technical work online. Sensitive information such as credentials, proprietary workflows, or company-specific data should never be included publicly. During my code review, I identified hardcoded database credentials as an example of a security issue, and that issue has since been resolved in the enhanced artifact by replacing the credentials with environment variable lookups. To reduce remaining risks while maximizing professional value, I am now doing a final pass to confirm the uploaded code and notebooks are sanitized, properly documented, and professionally organized. Through this course I have strengthened my understanding of software engineering, algorithms, databases, and secure coding practices, and I am now focused on finalizing the presentation and professionalism of the completed ePortfolio.
